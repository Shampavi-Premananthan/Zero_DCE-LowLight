========================================
DEPLOYMENT STEPS:
========================================

1. GO TO: https://huggingface.co/new-space

2. FILL IN:
   - Space name: (e.g., zero-dce-enhancement)
   - License: Apache-2.0
   - Select SDK: **Docker** (NOT Gradio!)
   - Space hardware: CPU basic (free) or T4 GPU

3. UPLOAD FILES IN THIS ORDER:
   a) README.md (MUST be first - contains Docker config)
   b) Dockerfile
   c) requirements.txt
   d) app.py
   e) Zero-DCE_code/ (entire folder)
      - Includes model.py, dataloader.py, Myloss.py
      - Includes snapshots/Epoch99.pth (80MB model)

4. WAIT:
   - Build takes 5-10 minutes
   - Check "Building" status at top of page
   - View logs if errors occur

5. TEST:
   - Once live, upload a dark image
   - Should see 2 outputs: 4-iteration and 8-iteration
   - Processing takes 40-60 seconds
